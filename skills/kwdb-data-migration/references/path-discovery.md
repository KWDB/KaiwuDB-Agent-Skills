# KaiwuDB Migration Full Workflow

1. Confirm source type and target engine.

2. Verify connection and permissions.

3. Check data type compatibility.

4. Configure mandatory parameters.

5. Set migration policy: filters, slicing, batch.

6. Validate configuration.

7. Export JSON config.

8. Run via GUI or Headless.

9. Check logs and row count.

10. Finish and verify consistency.
